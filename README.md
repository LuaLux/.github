# .github

Organisation-level defaults for [nebra-lang](https://github.com/nebra-lang).

## What lives here

| Path | Purpose |
|------|---------|
| `profile/README.md` | The org profile page shown at <https://github.com/nebra-lang> |
| `profile/banner.png` | Banner used by the profile page |

GitHub renders `profile/README.md` on the organisation landing page. Everything else in
this repository is inherited by repos that do not define their own copy, which is why
issue templates and shared workflows belong here rather than in each project.

## Looking for the language?

The compiler and toolchain live in [nebra-lang/nebra](https://github.com/nebra-lang/nebra).
Documentation is at <https://nebra-lang.github.io>.
